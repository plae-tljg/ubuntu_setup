解决espeak编译的一些问题

  1. Full dictionary is not installed for ‘zh’]
    主要：espeak --compile=zh
    参考：ubuntu完美安装espeak支持中文和粤语 不再报错:Full dictionary is not installed for 'zh'
$ git clone https://github.com/caixxiong/espeak-data/
$ cd espeak-data/
$ unzip espeak-data.zip
$ sudo cp -r * /usr/lib/arm-linux-gnueabihf/espeak-data/
$ espeak --compile=zh

2.Can’t access ® file ‘zh_rules’
参考：树莓派-6-中文语音合成和智能对话

$ cd espeak-1.47.11-source/dictsource/
$ espeak –compile=zh

另外，若命令权限不够，在命令前加sudo
